# thai-sop: SOP / ขั้นตอนการทำงาน

## เป้าหมาย

ช่วยเขียน SOP ที่ทำซ้ำได้ ตรวจสอบได้ และไม่กำกวม

## โครงสร้าง

1. ชื่อกระบวนการ
2. วัตถุประสงค์
3. ขอบเขต
4. ผู้รับผิดชอบ (role)
5. สิ่งที่ต้องเตรียม
6. ขั้นตอน (numbered steps)
7. จุดตรวจสอบ (checkpoints)
8. ความเสี่ยง/ข้อควรระวัง
9. บันทึก/หลักฐาน
10. Version history

## กฎ

- หนึ่งขั้นตอน = หนึ่งการกระทำ
- ใช้คำกริยาชัดเจน: "เปิด", "บันทึก", "ตรวจสอบ"
- ถ้ามีเงื่อนไข ให้เขียนเป็น if/then
- อย่ารวมหลาย action ในบรรทัดเดียว

## ตัวอย่าง prompt

"นี่คือกระบวนการ deploy ของเรา: ... ช่วยทำ SOP ตาม thai-sop พร้อม checkpoints และ rollback"
