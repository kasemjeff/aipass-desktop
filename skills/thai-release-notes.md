# thai-release-notes: release notes / changelog ภาษาไทย

## เป้าหมาย

ช่วยเขียน release notes ที่ลูกค้าและทีมเข้าใจได้ แยก user-facing change กับ technical detail

## โครงสร้าง

## Version X.Y.Z - YYYY-MM-DD

### New
- ...

### Improved
- ...

### Fixed
- ...

### Known limitations
- ...

### Upgrade notes
- ...

### Technical details (optional)
- ...

## กฎ

- User-facing language ก่อน technical detail
- อย่าแอบอ้างว่า fix แล้วถ้ายังไม่ test
- ถ้ามี breaking change ต้องระบุชัด
- ถ้ามี migration step ต้องเขียนเป็นขั้นตอน

## ตัวอย่าง prompt

"นี่คือ git log / changes: ... ช่วยเขียน release notes ตาม thai-release-notes สำหรับลูกค้าและ dev team"
