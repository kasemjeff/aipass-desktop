# thai-kb-article: บทความ knowledge base

## เป้าหมาย

เขียนบทความ KB ที่ค้นหาได้ ใช้งานได้จริง และไม่กำกวม

## โครงสร้าง

1. Title (ชัดเจน)
2. Problem
3. Cause (ถ้าทราบ)
4. Solution (ขั้นตอน)
5. Verification
6. Related links
7. Last updated

## กฎ

- หนึ่งบทความ = หนึ่งปัญหา
- ขั้นตอนต้องทำตามได้
- อย่าใส่ข้อมูลลับ
- ใช้ screenshot/diagram ถ้าจำเป็น

## ตัวอย่าง prompt

"นี่คือปัญหาที่ลูกค้าเจอบ่อย: ... ช่วยเขียน KB article ตาม thai-kb-article"
