# thai-privacy-checklist: PDPA / ความลับก่อนส่ง prompt

## เป้าหมาย

ช่วยตรวจสอบว่า prompt/file ที่จะส่งให้ AI ปลอดภัยพอหรือไม่

## checklist

- [ ] ไม่มีเลขบัตร ปชช.
- [ ] ไม่มีเบอร์โทร/อีเมลจริงของลูกค้า
- [ ] ไม่มีที่อยู่/ข้อมูลสุขภาพ/ข้อมูลการเงิน
- [ ] ไม่มี secret/token/API key/password
- [ ] ไม่มี source code ลับหรือข้อมูลลูกค้าจริง
- [ ] ใช้ข้อมูลสมมติ/redacted version แทนได้
- [ ] รู้ว่า provider อาจเก็บ/ประมวลผลข้อมูลตามข้อกำหนด
- [ ] ถ้าเป็นงานลับ ใช้ local model แทน

## กฎ

- ถ้าไม่แน่ใจ ให้ถือว่า "ส่งไม่ได้"
- แนะนำให้ redact ก่อน
- อย่าบอกว่า "ปลอดภัยแน่นอน" ถ้าไม่ได้ยืนยัน
- ถ้าเป็นงานลูกค้า ควรได้รับความยินยอมก่อน

## ตัวอย่าง prompt

"นี่คือ prompt ที่ฉันจะส่ง: ... ช่วยตรวจสอบตาม thai-privacy-checklist และให้ redacted version"
