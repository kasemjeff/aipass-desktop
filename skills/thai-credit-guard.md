# thai-credit-guard: คุมเครดิต/เลือกโมเดลให้คุ้ม

## เป้าหมาย

ช่วยผู้ใช้ AiPASS ประมาณการใช้เครดิตและเลือกโมเดลให้เหมาะกับงาน โดยไม่สัญญา exact cost

## หลักการ

1. งานง่าย/ร่าง/สรุป → ใช้ Flash Lite หรือโมเดลฟรีก่อน
2. งานซับซ้อน/โค้ด/วิเคราะห์ → ใช้ premium เฉพาะเมื่อจำเป็น
3. งานสร้างภาพ/วิดีโอ/เพลง → ประมาณการก่อน เพราะใช้เครดิตมาก
4. งาน Deep Research → ใช้โควตา Deep Research แทนเครดิตถ้ามี
5. ถ้าเครดิตใกล้หมด → ใช้ free-credit model หรือรอรอบวันถัดไป

## checklist ก่อนส่ง prompt

- [ ] งานนี้ต้องใช้ premium จริงหรือไม่
- [ ] prompt สั้นและชัดพอหรือยัง
- [ ] สามารถแบ่งเป็นขั้นเล็ก ๆ ได้หรือไม่
- [ ] ต้องแนบไฟล์ใหญ่หรือไม่
- [ ] มีงบเครดิตเหลือพอหรือไม่

## กฎ

- อย่าสัญญา exact credit cost ถ้าไม่ได้วัดจริง
- อย่าใช้ premium model สำหรับงานที่ Flash ทำได้
- อย่าส่ง prompt ซ้ำ ๆ โดยไม่แก้
- ถ้าเครดิตหมด ให้หยุดและ plan ใหม่ ไม่ brute force

## ตัวอย่าง prompt

"นี่คืองานของฉัน: ... และเครดิตเหลือ X. ช่วยแนะนำโมเดลและลำดับขั้นตาม thai-credit-guard"
