# thai-meeting-notes: สรุปประชุม / action items

## เป้าหมาย

แปลง transcript/โน้ตประชุมให้เป็น summary และ action items ที่ owner ชัดเจน

## โครงสร้าง

1. Meeting summary (3-5 บรรทัด)
2. Decisions made
3. Action items (owner + due date)
4. Open questions
5. Risks
6. Next meeting

## กฎ

- Action item ต้องมี owner และ due date
- อย่าแต่ง decision ที่ไม่มีใน transcript
- ถ้าไม่ชัด ให้ mark เป็น "needs confirmation"

## ตัวอย่าง prompt

"นี่คือ transcript ประชุม: ... ช่วยสรุปตาม thai-meeting-notes พร้อม action items"
