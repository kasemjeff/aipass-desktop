# thai-client-status: สรุปสถานะงานสำหรับลูกค้า

## เป้าหมาย

ช่วยเขียน update สั้น ๆ ให้ลูกค้าเข้าใจสถานะงาน, ความเสี่ยง, และสิ่งที่ต้องการจากลูกค้า

## โครงสร้าง

1. สรุป 3 บรรทัด
2. ทำเสร็จแล้ว (Done)
3. กำลังทำ (In progress)
4. ติดขัด/ความเสี่ยง (Blocked/Risks)
5. สิ่งที่ต้องการจากลูกค้า (Action required)
6. Timeline ถัดไป
7. Next update date

## น้ำเสียง

- ภาษาไทยสุภาพ ชัดเจน ไม่ใช้ศัพท์ dev มากเกินไป
- ระบุ "ความเสี่ยง" อย่างตรงไปตรงมา
- อย่า over-promise

## ตัวอย่าง prompt

"นี่คือ update ดิบ: ... ช่วยเขียน client status ตาม thai-client-status ให้สุภาพและมี action required"
