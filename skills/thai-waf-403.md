# thai-waf-403: วินิจฉัย 403 / edge refusal

## เป้าหมาย

ช่วยอธิบายว่าทำไม prompt อาจถูก edge ปฏิเสธ และวิธีแก้แบบไม่ bypass

## หลักการ

- 403 จาก edge มักเกิดจาก "เนื้อหาใน prompt" ไม่ใช่ความยาวเพียงอย่างเดียว
- การส่งซ้ำข้อความเดิมจะถูกปฏิเสธอีก
- อย่าพยายามหลบ/เข้ารหัส/ย่อให้หลุด detection เพื่อหลอก edge
- ให้ rewrite อย่างโปร่งใส หรือย้ายงานลับไป local model

## ขั้นตอน

1. ดูว่า prompt มีคำ/โค้ดที่เสี่ยงหรือไม่
2. แยกงานเป็นส่วนเล็ก ๆ
3. ใช้ข้อมูลสมมติ/redacted แทนข้อมูลจริง
4. ถ้าเป็น security review ให้ใช้ local model หรือ offline tool
5. บันทึกว่าเกิดกี่ครั้งและส่ง feedback ทางการ

## ห้าม

- ห้าม bypass WAF
- ห้าม automate เพื่อหลบ block
- ห้าม shale account/token
- ห้ามแอบอ้างว่า official

## ตัวอย่าง prompt

"นี่คือ prompt ที่โดน 403: ... ช่วยวินิจฉัยตาม thai-waf-403 และให้ rewrite ที่โปร่งใส"
